# 栞 Shiori — Interactive Japanese EPUB & Manga Reader

A local web app for learning Japanese by reading your own EPUB books and EPUB/CBZ manga volumes. Shiori combines `<ruby>`-aware word tokenization, CPU-powered manga speech-bubble OCR, monolingual-first lookups, context-aware grammar Q&A, passage/note saving, automatic difficulty tracking, and zero-backlog mini-games—without turning reading into a flashcard chore.

---

## Core Workflow & Features

### 1. EPUB Novel Parsing & Japanese Reading Ergonomics
- **Automatic Library Scanning:** Drop DRM-free `.epub` novels into `books/` and `.epub` / `.cbz` manga volumes into `manga/` (nested subfolders are scanned recursively), then click **Rescan Library** (or restart the server). All content is read directly from your local archives without modifying the original files.
- **Spine & Heading Chapter Grouping:** Works cleanly even on EPUBs whose `toc.ncx` only lists cover and colophon by grouping OPF `<spine>` XHTML files around logical chapter headings while preserving interleaved illustrations.
- **`<ruby>`-Aware `SudachiPy` Tokenization (Mode C):** Preserves multi-character `<rb>/<rt>` furigana and okurigana inside clickable word spans (lemmatized to dictionary forms for conjugated verbs/adjectives) and segments text into trackable sentences.
- **Reader Controls:**
  - **Horizontal / Vertical Layout:** Horizontal reading by default, with a one-click toggle to `vertical-rl` (including mouse-wheel vertical-to-horizontal scroll mapping).
  - **4 Progressive Furigana Modes:** Cycle `All` → `Trouble` (shows furigana only on words on your Trouble Radar or on hover) → `Hover` → `Off`.
  - **Themes & Typography:** `Paper`, `Sepia`, and `Dark` themes, adjustable font size (`A-` / `A+`), and automatic scroll-position + active-reading-time persistence per book.

### 1b. Manga Reader (`.epub` & `.cbz`)
- **2-Page RTL Spreads & 1-Page Vertical Mode:** Switch anytime between authentic Japanese right-to-left **2-Page Spreads** (with automatic solo handling for wide spreads and a **`Cover: Solo` / `Cover: Paired`** offset toggle) and seamless **1-Page Vertical** scroll (`V`).
- **Original Aspect Ratio & Fullscreen (`F`):** Images always preserve their exact native aspect ratio without cropping or distortion. Enter **Fullscreen** (`F`) for an uncluttered dark view of the pages where the top toolbar auto-hides cleanly (hover the top edge to reveal) while word lookup popovers, grammar chat, and modals remain usable right over the artwork.
- **Automatic & Manual Speech-Bubble OCR:** When optional `manga-ocr` extras are installed (`uv sync --extra manga-ocr`), visible pages run CPU-only OCR via `mokuro` + `manga-ocr` (leaving GPU VRAM dedicated to local LLMs) and cache clickable speech-bubble overlays in SQLite. You can also crop any box on the page anytime with **`✂ Select Area`** (`C`) or **`Shift + Drag`**, inspect clickable `SudachiPy` tokens, edit OCR text inline if needed, highlight substrings for **`Look Up` / `Chat` / `? Grammar` / `★ Save`**, and click the left/right edges (`←` / `→` / `Space`) to turn pages.

### 2. Two-Step Dictionary Lookup (Japanese-First → Optional English)
1. **Step 1 — Easy Japanese (J-J):** Clicking any word opens a floating card showing its dictionary form, reading, part of speech, a short learner-friendly Japanese definition, contextual nuance, and 2 everyday example sentences generated by your configured LLM (**local `llama.cpp`**, **local Ollama**, or **Google Gemini API**) and cached permanently in SQLite. If no LLM is running, the card degrades gracefully so Step 2 still works.
2. **Step 2 — Optional Offline English:** Click **`英語を見る / Show English`** to reveal instant offline **JMdict** definitions via `Jamdict`.

### 3. Inline Context-Aware Grammar & Passage Chat
- Click the **`?`** button at the end of any sentence—or select any text in the reader—to open the side drawer:
  - **`? Grammar`**: Runs a 1-click concise English grammar & nuance breakdown (Japanese words/particles quoted inline).
  - **`Chat`**: Opens the drawer with your selected passage attached and focuses the input box without auto-sending a default prompt so you can ask your own custom question right away.
  - **`Look Up`**: Directly opens the 2-step lookup popover for any manually selected text span (helpful if a compound or phrase wasn't tokenized as a single clickable word).
- Ask follow-up questions in multi-turn conversations, browse saved **Chapter Notes**, and jump back to highlighted sentences.

### 4. Saved Quotes & Free-Form Notes (`栞 Notes`)
- **Highlight & Save:** Select any passage (1–1,500 characters, including multi-sentence quotes) and click **`★ Save`**, or click **`★ Save Note`** inside a word lookup card.
- **No Lookup Required:** Open **`栞 Notes`** from the reader bar or library header anytime to write standalone reading reflections, chapter summaries, or expressions without looking up a single word.
- **Organize & Jump Back:** Tag entries as **Favorite Quote**, **Reading / Study Note**, or **Expression / Idiom**, filter by scope (`This Chapter` / `This Book` / `All Books`) and category, edit or delete entries, and click **`Jump`** to scroll straight back to the saved sentence.

### 5. Automatic Trouble Radar & Idle-Aware Timer
- **Zero Manual Card Creation:** Shiori tracks implicit signals automatically:
  - Step 1 J-J lookup (`+0.5`)
  - Step 2 English reveal (`+2.0`)
  - Grammar Q&A ask (`+2.5`)
  - Re-encountering trouble across different chapters (`+1.0`)
- **Visual Cues & Control:** High-trouble words (`score >= 3.0`) receive a subtle dotted underline. Open **Radar** to inspect active items, manually **Mark Known** or **Restore**, or review past quiz scores.
- **Idle-Aware Reading Timer:** Tracks active reading time in the top bar (pauses automatically after 60s of inactivity or when the tab/reader is hidden), supports `Off` / `10m` / `15m` / `20m` / `30m` intervals, and pulses **`Review Ready`** gently when your goal is reached.

### 6. Zero-Backlog Long-Term Retention Mini-Games
Trigger a 10-question round from **Clear Chapter Quiz (10 Qs)** at the end of a chapter, **Review Quiz** in the timer popover, **Radar**, or the **`Done · Quiz`** session wrap-up button (which saves progress and mixes cooled-down aged items with fresh trouble items from the current reading session):

- **Typed Reading Recall (`typed_reading`):** Active recall without multiple-choice hints for JMdict-verified kanji words—type any valid hiragana reading directly with live romaji-to-hiragana conversion (`static/js/romaji.js`), or click **`Show 4 Choices`** if you need a nudge.
- **Kanji → Reading (`reading_recall`):** Isolated JMdict-verified word with no furigana and no story context; pick the right hiragana reading against phonetic distractors that exclude valid alternate readings.
- **Word → Meaning (`meaning_match`):** Isolated word matched against offline **JMdict** dictionary definitions with disjoint gloss distractors.
- **Meaning → Word (`def_to_word`):** Reverse recall from offline JMdict dictionary definition back to the Japanese word.
- **Vocab Match-Up (`match_pairs`):** Interactive 4-pair word-to-JMdict-meaning board updating all included trouble words together.
- **Text Context Cloze (`cloze`):** Capped at most 1 per round, strictly matched on exact whole-word token spans inside real chapter sentences.
- **Bunsetsu Scramble (`scramble`):** Splits exact chapter sentences into grammatical chunks via `SudachiPy` and grades exact sentence reconstruction.
- **Particle Fix (`particle`):** Blanks an isolated particle (`は`, `が`, `を`, `に`, `で`, `も`, etc.) inside an exact chapter sentence with confusable choices.

**3-Stage Cool-Down Spacing (No Backlog):** Stage `0` trouble items fade their automatic `Trouble`-mode furigana once recalled correctly and advance to Stage `1` (`20h` cool-down), then Stage `2` (`72h` cool-down), and finally retire at Stage `3`. Incorrect answers reset an item back to Stage `0`. Each 10-question round prioritizes up to 5 cooled-down aged items alongside fresh trouble words and skips items still inside their cool-down window—so you get real spacing without an accumulating due queue.

### Keyboard Shortcuts
- **Novels:** `[` / `]` for Previous / Next chapter
- **Manga:** `←` or `Space` (Next page RTL), `→` (Previous page RTL), `F` (Fullscreen), `V` (2-Page Spread / 1-Page Vertical), `S` (Cover Solo / Paired), `C` (Select Area OCR; or hold `Shift + Drag`)
- **Quizzes:** `1`–`4` for multiple-choice answers, `Enter` to advance after feedback (or send in Grammar Chat; `Shift+Enter` for newline)
- **Global:** `Escape` to close open popovers, inspect bars, drawers, or modals

## Architecture & Tech Stack

- **Backend:** Python 3.12+, [FastAPI](https://fastapi.tiangolo.com/), SQLite (WAL mode), `BeautifulSoup4` + `lxml`
- **Japanese NLP & Dictionary:** `SudachiPy` (`sudachidict-core`, Mode C) + offline JMdict via `Jamdict`
- **LLM Providers:** Local **`llama.cpp` (`llama-server` OpenAI-compatible API, default)**, local **Ollama** (`httpx`), or **Google Gemini API** (`google-genai`), switchable in **Settings** and sharing one SQLite cache
- **Frontend:** Zero-build modular HTML/CSS/ES modules served from `static/` — all state lives behind `/api/*` JSON endpoints so the UI can later be replaced with React or Svelte without touching the backend.

## Setup & Installation

### Prerequisites
- Python 3.12 (`uv` manages it automatically)
- [uv](https://docs.astral.sh/uv/)
- *(Optional)* [llama.cpp](https://github.com/ggml-org/llama.cpp) (`llama-server`) or [Ollama](https://ollama.com/) for local AI explanations, or a Google AI Studio key for Gemini API

### Steps

1. **Install dependencies:**

   ```powershell
   uv sync
   ```

   *(Optional — for local CPU manga speech-bubble & crop OCR:)*

   ```powershell
   uv sync --extra manga-ocr
   ```

2. **Download the offline JMdict dictionary database (`data/jamdict.db`):**

   ```powershell
   uv run python scripts/setup_dict.py
   ```

   *(Note: This script unpacks `jamdict-data` directly via Python's `lzma` module to avoid a Windows file-locking issue in the upstream `jamdict-data` installer.)*

3. **Add your books and manga:**
   Place DRM-free Japanese novel `.epub` files inside `books/`, and manga `.epub` or `.cbz` files inside `manga/`.

4. **Configure an AI provider (optional):**
   - **`llama.cpp` (`llama-server`, Default Local & Free):** Place a `.gguf` model in `%LOCALAPPDATA%\Shiori\models` (Windows) or `~/models`—or set an explicit `.gguf` path in **Settings**. When `llama.cpp` is selected and auto-start is enabled, `uv run python run.py` automatically launches `llama-server` on `http://127.0.0.1:8080` and stops it when you exit. You can also run it manually:
     ```powershell
     llama-server -m path\to\model.gguf --port 8080 -ngl 99
     ```
     Open **Settings** to adjust the URL, GGUF path, auto-start toggle, optional API key, or refresh detected models from `/v1/models`.
   - **Ollama (Local & Free):** Switch **Provider** to **Ollama (Local)** in **Settings**, start Ollama, and pull a Japanese-capable model:
     ```powershell
     ollama pull qwen3:8b
     ```
     *(Alternatives for lighter VRAM: `gemma3:4b` or `qwen2.5:7b`.)*
   - **Gemini API:** Open **Settings** in the app, choose **Gemini API**, and paste your Google AI Studio API key (or set the `GEMINI_API_KEY` environment variable).
   - Offline reading, JMdict English lookups, note saving, Trouble Radar, and offline mini-games work even without an LLM configured.

## Running the App

```powershell
uv run python run.py
```

When `llama.cpp (Local)` is enabled with a local `.gguf` model, `run.py` automatically starts `llama-server` in the background (logged to `data/llama-server.log`) and shuts it down cleanly when you close the app.

Open **`http://127.0.0.1:8000`** in your browser.
